# 版本管理

由于不同的Operator CRD版本往往处于不同的开发进度，为了更好地区分这些CRD的状态及可用性，我们将所有CRD的状态分为4个阶段：Alpha、Beta和Release，用户可以在各个CRD的说明页上看到该CRD的状态，从而方便用户更好地进行方案选择。

## Alpha
任何初始PR提交的代码均处于该阶段。处于该阶段的CRD已经初步具备使用条件，可在非关键场景中使用，但可能存在以下情况：

- CRD的配置项/字段仍可更改，且不保证后向兼容；
- CRD可能存在功能错误和性能问题，用户可向社区反馈，但不一定得到立即响应。

## Beta
当一个处于Alpha阶段的CRD已经在部分非关键场景中稳定运行一段时间后，该CRD进入Beta阶段。处于该阶段的CRD已经基本达到稳定使用的条件，但仍然可能存在以下情况：

- CRD的配置项/字段仍可微调，但保证后向兼容；
- CRD仍然可能存在微小的功能错误和性能问题，用户向社区反馈后，CRD维护者将会尽快响应。

## Release
当处于Beta阶段的CRD满足以下条件后，该CRD正式进入稳定状态：

- 该CRD已被一定数量的社区用户在生产环境中使用，且运行稳定，无异常报告；
- 该CRD的功能已经完善，社区无新增相关issue，无未解决bug；
- 该CRD的配置项/字段已不再更改，且保证后向兼容。
