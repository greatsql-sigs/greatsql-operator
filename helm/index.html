🚀 GreatSQL Operator Helm Charts

Deploy GreatSQL Operator via Helm

🧭 Quick Start

Add this repository to Helm:

helm repo add greatsql https://greatsql-sigs.greatsql.cn/greatsql-operator
helm repo update

Install the GreatSQL Operator:

helm install greatsql-operator greatsql/greatsql-operator
